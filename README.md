## 🚀 Overview

**Neptune's Legacy** adalah sebuah dashboard monitoring maritim yang dirancang khusus untuk mengawasi aktivitas kapal di **Perairan Natuna**. Sistem ini mampu mengidentifikasi kapal yang diduga melakukan **IUU Fishing** (Illegal, Unreported, and Unregulated Fishing), mengirimkan peringatan (alert), serta memberikan opsi tindakan kepada otoritas keamanan untuk menindaklanjuti kapal-kapal tersebut.

**Live Site:** [https://neptunes-legacy.vercel.app/](https://neptunes-legacy.vercel.app/)

---

## 🌏 Background

Perairan Natuna merupakan salah satu wilayah perairan Indonesia yang rawan terhadap praktik **IUU Fishing** — aktivitas penangkapan ikan secara ilegal, tidak dilaporkan, dan tidak diatur. Praktik ini merugikan negara secara ekonomi maupun ekologis.

Neptune's Legacy hadir sebagai solusi teknologi untuk membantu otoritas maritim dalam:

- 🛰️ **Memantau** pergerakan kapal di Perairan Natuna secara real-time
- 🚨 **Mendeteksi** kapal yang dicurigai melakukan IUU Fishing
- ⚡ **Memberikan respons cepat** melalui sistem alert & opsi tindakan

## 🏁 Getting Started

### Prerequisites

Pastikan kamu telah menginstal:

- [Node.js](https://nodejs.org/) (v16 atau lebih tinggi)
- [npm](https://www.npmjs.com/) atau [yarn](https://yarnpkg.com/)

### Installation
1. Clone repository
   git clone https://github.com/fvrIq/neptunes-legacy.git

2. Masuk ke direktori project
    cd neptunes-legacy
    
3. Install dependencies
    npm install
    
4. Jalankan development server
    npm run dev

5. Buka di browser
    http://localhost:5173



📜 Available Scripts
| Command | Description |
|---------|-------------|
| `npm run dev` | Menjalankan development server |
| `npm run build` | Build untuk production |
| `npm run preview` | Preview hasil build production secara lokal |
| `npm run lint` | Menjalankan ESLint (jika dikonfigurasi) |
